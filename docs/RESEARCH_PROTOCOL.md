# 预注册式研究协议

## 1. 研究边界

本研究完全基于**公开数据集上的数值仿真**。论文不包含物理光学平台或真实边缘设备实验。所有光学层均由标量衍射传播模型模拟。包含实体实验的论文仅作为外部背景或建模依据，不构成本项目实验数据或验证结论。

## 2. 待验证研究问题

- **RQ1：** 标准 D2NN 在干净数据上的分类性能能否由当前实现复现？
- **RQ2：** 相位噪声、层间横向错位、相位量化和探测器噪声分别造成多大性能退化？
- **RQ3：** 将制造与部署扰动纳入训练后，鲁棒性是否提升，干净条件性能付出多少代价？
- **RQ4：** 光学特征提取与轻量电子分类器联合优化，是否优于纯光学读出和参数量匹配的纯电子基线？
- **RQ5：** 在相同数据、精度目标与计时边界下，各方案的软件仿真延迟、参数量、估算运算量和中间表示规模如何变化？

这些问题当前均为待检验问题，不是论文结论。

## 3. 候选实验矩阵

| 维度 | 预注册候选值 | 说明 |
|---|---|---|
| 数据集 | MNIST；Fashion-MNIST；必要时增加公开灰度数据集 | 最终选择取决于基线代码与计算资源 |
| 模型 | 纯电子 CNN/MLP；标准 D2NN；鲁棒 D2NN；混合 D2NN+电子头 | 基线需参数与训练协议透明 |
| 相位噪声 | 多级标准差扫描 | 单位与分布由物理模型和文献确定 |
| 横向错位 | 多级像素/物理长度扫描 | 必须记录采样间距和传播参数 |
| 相位量化 | 多种比特宽度 | 与连续相位模型比较 |
| 探测器噪声 | 光子/高斯/读出噪声候选 | 只采用有文献或设备依据的模型 |
| 训练重复 | pilot 可用 1 个种子；正式比较目标 5 个、最低 3 个种子 | 各方法使用同一组配对种子；若仅 3 个种子，明确标注区间精度有限 |
| 部署扰动重复 | 每个强度使用固定数量的扰动 draw | draw 数在计时 pilot 后、主结果运行前冻结；各方法复用相同 draw ID |

## 4. 数据与划分

- 使用公开、许可证明确的数据集。
- 下载脚本保存来源 URL、下载日期和文件校验和。
- 数据划分由固定脚本生成并保存样本索引。
- 测试集只用于最终评估；超参数选择使用训练集/验证集。

## 5. 统计与报告

- 主指标：分类准确率与宏平均 F1；类别不平衡时补充每类指标。
- 鲁棒性：报告性能—扰动强度曲线及相对/绝对下降。
- 模型比较的独立统计单位是**训练随机种子对应的独立模型运行**。测试样本、同一模型下的扰动 draw 和计时循环均不得冒充独立训练重复。
- 每个训练种子与扰动强度先在固定 draw 集上汇总，再跨种子报告均值、标准差、所有单个种子值和基于种子级统计量的 95% t 区间。若仅有 3 个种子，正文明确说明区间不稳定且结论属于有限重复下的仿真证据。
- 方法间比较使用相同的数据划分、训练种子和扰动 draw ID，主效应报告种子级配对差值。默认不以 p 值筛选结论；若结果冻结前预先指定少量推断性比较，则报告配对检验、效应量、精确 p 值，并对同一比较族使用 Holm 校正。
- 扰动 draw 反映给定训练模型下的部署噪声变化，单独报告 draw 内离散度，不与训练种子合并为更大的 `n`。
- CPU 计时循环属于技术重复：固定线程数和 batch size，预热后报告中位数、四分位距及完整重复次数，不把单个 batch 计时当作独立设备样本。
- 失败实验和负结果保留在日志中，不静默删除。
- CPU 计时仅表征固定软件环境中的仿真实现开销；正文必须使用“CPU 软件仿真延迟”或等价限定语，不得写成边缘设备延迟、吞吐或性能。
- 不计算或声称真实设备功耗、能效和光学端到端时延；若讨论这些量，只能引用并明确标注为“文献报告值”，且不得与本研究仿真结果混合比较。

## 6. 可复现产物

每次正式实验必须产生：

1. 完整配置文件；
2. 环境与硬件快照；
3. 标准输出日志；
4. Checkpoint；
5. 逐样本预测；
6. 汇总指标 JSON/CSV；
7. 图表生成脚本；
8. 与 `EVIDENCE_LEDGER.md` 对应的 Metric ID。

## 7. 文献与开源证据可追溯性

- `references.bib` 是论文的机器可读书目入口；正文使用的每个 BibTeX key 必须存在于该文件并保留 DOI 或稳定 URL。
- 每篇被引用论文必须在 `LITERATURE_MATRIX.md` 中具有同 key、同 DOI/URL 的记录，并注明方法、仿真/实体实验属性、可支持论点、禁止外推内容和代码/数据开放状态。
- 每条用于论证的外部来源必须在 `EVIDENCE_LEDGER.md` 的 B 表登记；论文通过 DOI/URL 对齐三份记录。开源实现还必须在 `THIRD_PARTY.md` 记录仓库 URL、固定提交、许可证和本地核验结果。
- 任一环节缺失或标识不一致时，该来源不得用于支撑论文主张或定量比较。

## 8. 论文写作门槛

- 方法章节可在实验前形成草稿，但所有参数必须来自实现或可核验文献。
- 结果章节只读取机器生成的结果文件。
- 摘要中的定量结论必须等实验冻结后填写。
- 引言最终版在结果冻结后重写，确保每项贡献均有对应实验。

## 9. 正式 MNIST v1 冻结

正式 MNIST 实验矩阵已于 2026-07-29 在任何正式训练运行前冻结到 `FORMAL_EXPERIMENT_PROTOCOL.json`。该文件规定：

- 训练 seed 为 42、43、44；每个方法 3 epoch，统一 64×64、3 层、FFT Rayleigh–Sommerfeld 数值传播配置；
- 方法为标准 D2NN、扰动感知 D2NN、混合 D2NN+电子头和参数量相近的纯电子基线；纯电子方法不参与不适用的光学扰动配对；
- 全部正式光学评估使用完整 10,000 样本测试集；随机条件每个 seed 使用 3 个冻结 draw，确定性 clean/量化条件使用 1 个 draw；
- 主指标为准确率与从整数混淆矩阵重算的 macro-F1；独立统计单位始终是训练 seed；
- 横向错位、层间距误差、相位噪声和合成探测器噪声范围属于工程敏感性网格，不声称由真实硬件标定；
- 单 draw 完整测试集预算 pilot 的 `20.953 s` 包含进程启动、加载、推理和写盘，只用于选择可承担的 draw 数，不属于论文 CPU 软件仿真延迟指标。

冻结后不得依据 pilot 或测试结果修改 epoch、seed、方法、扰动范围或 draw 数。若因明确实现错误必须修订，须新建协议版本并保留本版本，不得静默覆盖。
