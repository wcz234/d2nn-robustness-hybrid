## 使用边界

1. 本矩阵只证明文献中已报告的方法与结果，不证明本项目已经复现它们。
2. 论文正文引用任何文献数值时，必须同时写明其数据集、光学配置、仿真/实体实验属性和评价指标。
3. 本项目完全基于数值仿真。物理原型、现场链路和器件测量只能作为相关工作或设计动机，不能作为本文实验数据。
4. “未核验到代码/数据仓库”不能写成“作者未公开”；后续若发现作者仓库，应登记 URL、许可证、固定提交和复现状态。
